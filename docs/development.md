# 实现与验收记录

## 第六批：窗格目录树、近期记录与常用位置画像

每个窗格增加独立目录树和系统文件夹选择器。常用、最近、当前位置与磁盘入口可以直接设置窗格路径，树与文件列表间的边界可拖动，宽度和开关随工作区保存。工作区 JSON 使用可选字段保持旧数据兼容。

新增独立 SQLite `navigation.db`，记录 Catena 中的成功目录导航与文件打开。启动恢复与刷新不增加访问次数。记录跨窗格共享，最多保留 300 个位置、90 天，显示最近 30 个；退出时等待已发起的记录写入。

常用位置自动发现 OneDrive，支持新增、移除、后台更新与取消。结构扫描仅读取元数据，生成类型与分支分布、数量、大小、层级和最近修改时间。完整快照事务提交；部分扫描合并已知条目，离线或取消不清空原缓存，已删除的常用位置不会被迟到的扫描恢复。完整画像启动时按 24 小时过期更新，目录树展开按 5 分钟过期更新，暂无实时文件监听。

Windows 扫描通过目录枚举的重解析标记区分云目录与目录别名，允许 CLOUD 系列标记，跳过 junction、符号链接和其他未知类型。在线文件自动预览先检查 Offline / Recall 属性，避免选中即下载正文。

## 关键实现决定

- 本地读取通过后台生产者与有界通道返回批次，队列最多积压两批。消费结束会取消生产者。
- 窗格导航独立保存请求编号，新请求取消旧请求。即使 Provider 忽略取消，旧结果也不能更新当前窗格。
- 加载期间渐进显示，加载完成后按所选字段排序；列表容器虚拟化。
- 固定目录是返回锚点，允许继续浏览其他目录。首版没有范围锁定模式。
- 自动保存采用 700 ms 防抖，正常退出等待事务提交。只在 SQLite session 表记录最后活动工作区 ID。
- 布局和窗格状态以带版本的 JSON 保存到 SQLite，避免首版过度拆分状态表。业务层不接触 SQL。
- 搜索取消和模式切换会使旧请求失效。当前搜索只使用文件名，不扫描文件内容。
- MVVM 命令供按钮与快捷键复用。只为已经落地的能力建立工程，没有空插件项目。

## 0.6.0 搜索与本机集成

Everything 改用 Unicode QUERY2 IPC。常驻消息线程为每个并发请求创建独立回复窗口，避免 Everything 同一窗口的新请求取消其他窗格查询。请求有超时、取消、结果大小限制和二进制边界检查。普通关键词使用引用文本匹配；含通配符或引号时仍按字面量编码，防止变成搜索操作符。ES 保留作对照，应用默认不启动 ES 进程，也不写临时搜索文件。

顶部输入框先确定范围和方式，提交后展示各窗格独立的结果窗口。默认递归搜索工作区可见窗格的所有目录，路径边界避免同前缀目录误入，重叠目录由单次索引查询自然去重。索引错误明确显示，只在用户选择后改用本地递归扫描。结果集合整体替换，减少通知和布局次数。

设置分为六类，外观支持系统、浅色、深色及内置蓝雾背景。背景由内置 imagegen 生成，资源与提示词在 `src/Catena.App/Assets`，按需解码并释放。列表缩放范围 75%–200%，保存到 PaneState，仍使用虚拟列表；1 万条目在缩放后实际容器仍不超过 100。标题栏透明背景接收空白区域指针事件，功能控件排除拖动。

PDF 使用 [Windows.Data.Pdf](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfdocument) 渲染并支持分页。PPTX/PPTM 使用已有 Skia 依赖绘制 Open XML 中的文字、普通形状和嵌入图片，支持分页，复杂母版、图表及组合变换不完整还原。压缩包、XML、图像大小有上限，外部关系不读取，不执行宏。Word 使用进程外系统预览处理程序；未注册时 DOCX 保留正文回退。原生预览在单独 STA 消息线程运行，过期结果不显示，8 秒超时不阻塞主界面。在线文件检查 Offline/Recall 属性后只返回元数据。

原生预览采用 NativeControlHost；真实 EXE 启动检查发现缺少 supportedOS manifest 会导致创建子窗口失败，已补充 Windows 10/11 兼容声明并复测通过。不能仅以 Headless 渲染替代原生启动检查。
